# 网约车管理系统

基于 Go 语言实现的网约车后台管理系统，覆盖 7 个任务工单的全部模块：

| 工单 | 模块 | 说明 |
|---|---|---|
| 全栈开发-网约车-01 | 顺风车管理 | 实名认证、行程发布、紧急求助、行程分享、双向评价、司机车辆配置 |
| 全栈开发-网约车-02 | 班车管理 | 线路/站点管理（上下车站点排重、按时间自动排序）、排班 |
| 全栈开发-网约车-03 | 财务管理 | 收支对账、交易明细、自动账单、异常检测、争议处理 |
| 全栈开发-网约车-04 | 订单管理 | 班车/顺风车订单、退票（自动审核+人工复核）、批量退票、状态历史、评价管理 |
| 全栈开发-网约车-05 | 人员管理 | 员工/司机/乘客管理、多角色 RBAC、CSV/JSON 导入校验、批量操作 |
| 全栈开发-网约车-06 | 数据分析 | 订单量统计、增长率、转化率（漏斗）、复购周期分析 |
| 全栈开发-网约车-07 | 营销管理 | 优惠券创建/发放/使用、推广发码+推荐奖励、收藏分享、删除引用校验 |

## 技术栈

- **语言/框架**：Go 1.26 + Gin
- **ORM**：GORM（默认 SQLite 免安装直接运行，可切换 MySQL）
- **认证**：JWT + bcrypt 密码加密
- **权限**：RBAC 角色权限模型（多角色、接口级权限校验）
- **校验**：go-playground/validator（gin binding）
- **设计模式**：策略模式（优惠券计算、退票取消费）、工厂模式（优惠策略创建）
- **其他**：操作审计日志、异步导出任务、内存缓存（接口化，可替换 Redis）

## 快速开始

```powershell
# 环境变量（可选，均有默认值）
#   DB_DRIVER=sqlite|mysql   DB_DSN=mysql DSN
#   JWT_SECRET=xxx           SERVER_PORT=:8080
go run ./main.go
```

默认管理员账号：`admin / admin123`（首次启动自动初始化种子数据）

接口文档见 `docs/代码说明文档.md`。
