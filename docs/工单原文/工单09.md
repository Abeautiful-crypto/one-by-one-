2 任务描述（按需求/难点/解决/优化/扩展/改进 六段式表达）
1. 需求：围绕 GVA 框架在司机端高并发场景（订单管理、实时抢单、费用结算）下的能力升级，聚焦 动态权限菜单加载、多数据源路由、审计日志增强、Xxl Job 调度集成、设计模式沉淀 五大模块，形成可度量、可复用的工程实践与团队级范式，显著提升可维护性与可观测性，降低故障定位与调优成本。
2. 难点：解决 多实例下动态路由一致性与缓存失效、请求级数据源上下文透传与连接回收的并发安全、Casbin 策略命中与慢 SQL 跨域关联的审计留痕，以及 Xxl Job 参数在线热更新与一键回滚 等关键工程难题。
3. 解决：通过 源码级梳理 + 设计模式抽象 + 中间件统一治理，以 Casbin 策略 + 数据库驱动 + 本地缓存 + 变更通知实现动态路由装配与多实例一致；用 Gorm 多连接工厂 + 请求上下文 + 中间件 完成数据源键的线程级透传与连接回收；权限拦截点植入 结构化审计日志 并联动慢查询关联请求链路标识；沉淀 单例 / 工厂 / 策略 三类模式类图与说明；接入 Xxl Job v1.6.1 执行器与注册逻辑，支持参数在线配置与即时生效。
4. 优化：优化 关键路径搜索精确匹配 与 Casbin 命中短路，为 批量操作增加即时反馈与失败重试，审计日志输出字段键统一并打通链路标识；菜单装配时长、路由数量、审计写入时延、执行器心跳等核心指标接入 Prometheus 暴露，提升端到端可观测性。
5. 扩展：扩展后续可 插拔式策略适配器 接入更细粒度权限（按车辆/班次/区域），预留 灰度与读写分离 数据源扩展点；沉淀 设计模式手册 + 类图 + 适用场景 供团队复用，支持 多租户、慢查询报表、调度任务模板 等模块快速接入。
6. 改进：改进本工单中的 新技术与新技能，包括 GVA 源码级优化方法、中间件 + 上下文的数据源治理、Xxl Job v1.6.1 调度集成、Casbin 策略引擎在菜单/路由中的实战、Prometheus 指标体系 + 结构化审计日志，以及 基于类图沉淀的设计模式范式，形成可复制的工程实践模板。
3 验收标准
功能验收
动态菜单与路由可后台刷新并在多实例间一致；多数据源按请求上下文正确路由并支持灰度与回退；权限拦截点产生日志并可按用户/角色/路径查询；Xxl Job 任务参数在线更新即时生效并记录审计历史。
性能验收
动态装配路由耗时与实例数量线性可控，装配失败可重试；审计日志吞吐不低于 1000 条/秒并支持采样；多数据源切换不显著增加接口延迟，新增开销低于 5%。
安全验收
动态路由受白名单限制，拒绝任意处理器绑定；审计日志屏蔽敏感字段，管理接口鉴权完备；调度参数修改需鉴权并具备回滚能力。
代码质量
单元测试覆盖核心模块并通过竞态检测；目录与命名符合团队规范并附类图与说明；配置可观测化并具备告警阈值与演练文档。
